# Arvi Joento - Portfolio

Henkilökohtainen portfoliosivusto.

- **Koulu:** Turun ammattikorkeakoulu, Tuotantotalous (Insinööri AMK)
- **Yrittäminen:** WinFi Oy (Guuni-palvelualusta ja asuntoflippaus) sekä Pihahuolto Joento (toiminimi)
- **Urheilu:** RaiFu Futsal edustusjoukkue (#11)

## Teknologiat
- HTML5
- CSS3 (`style.css` ja `modern.css`, responsiivinen ulkoasu)
- Vanilla JavaScript (mm. interaktiivinen ennen/jälkeen-kuvavertailu keittiöremontista)

Julkinen sivu: https://ajoento.github.io/arvi-joento-portfolio/
